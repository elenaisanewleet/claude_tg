# Развёртывание на сервере

Коротко: **Vercel и подобные serverless-платформы не подойдут технически**, а
**сервер внутри России не подойдёт из-за геоблокировки Anthropic**. Ниже —
почему так и что работает.

---

## Почему не Vercel (и не Netlify / Cloudflare Workers)

Vercel запускает **функции**, а не процессы. Для claude-tg это несовместимо
сразу по четырём пунктам:

| Что нужно боту | Что даёт Vercel |
|---|---|
| Процесс живёт часами и держит соединение с Telegram | Функция живёт 10–60 секунд и умирает |
| Внутри запускается дочерний процесс `claude` (Node CLI) | Нельзя ставить и запускать сторонние бинарники |
| Постоянный диск: токен в `~/.claude`, SQLite, рабочие папки сессий | Файловая система только для чтения, кроме `/tmp`, который стирается |
| Одна сессия Claude живёт между сообщениями | Каждый вызов — новый холодный инстанс |

Это не вопрос тарифа: на платном Vercel бот тоже не заработает. Нужен обычный
сервер, где можно держать долгоживущий процесс — VPS, домашний компьютер или
PaaS с поддержкой background worker + диска.

## Почему не российский хостинг

Anthropic не обслуживает Россию — страна не входит в
[список поддерживаемых регионов](https://www.anthropic.com/supported-countries).
Запросы с российских IP отклоняются. Поэтому Beget, Timeweb с локацией в РФ,
bothost.ru, Amvera и любой другой сервер внутри страны не подойдут, каким бы
удобным ни был тариф.

Нужна машина **за пределами РФ**: Нидерланды, Германия, Финляндия, Польша,
Казахстан. Платить при этом можно рублями — см. ниже.

## Про «бесплатно»

Честно: бесплатного варианта, который одновременно (а) держит долгоживущий
процесс, (б) находится за границей и (в) не требует иностранную карту —
практически не существует.

* **Oracle Cloud Always Free** — действительно бесплатен навсегда (4 ARM-ядра,
  24 ГБ RAM), но при регистрации требует карту для верификации, и российские
  карты обычно не проходят.
* **Render / Railway / Fly.io** — бесплатные тарифы либо только для веб-сервисов
  с засыпанием и без постоянного диска, либо требуют карту.
* Российские бесплатные PaaS — отпадают по геоблокировке.

Поэтому реалистичных вариантов два.

---

## Вариант A: свой компьютер — бесплатно

Если мак (или любой домашний компьютер) и так включён — это самый простой и
буквально бесплатный путь. В репозитории уже лежит
[`deploy/com.claude-tg.bot.plist`](../deploy/com.claude-tg.bot.plist) для
автозапуска через launchd:

```bash
cp deploy/com.claude-tg.bot.plist ~/Library/LaunchAgents/
$EDITOR ~/Library/LaunchAgents/com.claude-tg.bot.plist   # заменить USERNAME
launchctl load -w ~/Library/LaunchAgents/com.claude-tg.bot.plist
```

Логи: `~/Library/Logs/claude-tg.log`. Бот поднимется сам после перезагрузки.
Минус ровно один — компьютер должен быть включён и в сети.

Для Linux-машины дома то же самое делает
[`deploy/claude-tg.service`](../deploy/claude-tg.service).

## Вариант B: VPS за границей с оплатой рублями — от ~150–450 ₽/мес

Не бесплатно, но иностранная карта не нужна: российские провайдеры продают
серверы в европейских дата-центрах и принимают карты «Мир», Visa/MC РФ, СБП и
ЮMoney.

| Провайдер | Локации за рубежом | Ориентир по цене |
|---|---|---|
| [Timeweb Cloud](https://timeweb.cloud/) | Амстердам, Франкфурт, Польша, Казахстан | от ~340 ₽/мес |
| [aeza](https://aeza.net/) | Германия, Нидерланды, Финляндия | от ~150 ₽/мес |
| [VDSina](https://vdsina.ru/) | Амстердам | от ~150 ₽/мес |
| [AdminVPS](https://adminvps.ru/) | Германия, Финляндия, Нидерланды | от ~449 ₽/мес |
| [HOSTKEY](https://hostkey.ru/) | Европа, США (принимает «Мир») | от ~500 ₽/мес |

Боту хватает самого дешёвого тарифа: **1 CPU / 1 ГБ RAM / 10 ГБ диска**.
Claude Code запускается как дочерний процесс и много не ест, но при 512 МБ
может упираться в память — лучше взять 1 ГБ.

## Авторизация на сервере без браузера

На сервере нет браузера, поэтому `claude auth login` там не сработает. Решение —
долгоживущий токен, который выдаётся **на твоём компьютере** и переносится на
сервер переменной окружения.

**Шаг 1 — на своём маке** (где Claude уже авторизован):

```bash
claude setup-token
```

Команда попросит подтвердить вход и напечатает токен вида `sk-ant-oat01-…`.
Он привязан к твоей подписке Claude — это полноценный ключ доступа, обращайся с
ним как с паролем.

**Шаг 2 — на сервере**, в `.env` рядом с токеном бота:

```dotenv
CLAUDE_CODE_OAUTH_TOKEN=sk-ant-oat01-…
```

Бот кладёт переменные из `.env` в своё окружение, а дочерний процесс `claude`
его наследует — отдельно ничего прокидывать не нужно.

> Альтернатива: если у тебя есть ключ Anthropic API (оплата по токенам, а не по
> подписке), можно вместо этого указать `ANTHROPIC_API_KEY`. Для подписки
> Pro/Max нужен именно `setup-token`.

## Пошагово: Ubuntu 24.04, systemd

```bash
# 1. Зависимости
sudo apt update && sudo apt install -y python3-venv git ripgrep curl
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm install -g @anthropic-ai/claude-code@latest

# 2. Код
sudo mkdir -p /opt/claude-tg && sudo chown "$USER" /opt/claude-tg
git clone https://github.com/smmsemmers/claude_tg.git /opt/claude-tg
cd /opt/claude-tg
./deploy/install.sh

# 3. Настройки
$EDITOR .env
#   TELEGRAM_BOT_TOKEN=…
#   OWNER_USER_ID=…
#   CLAUDE_CODE_OAUTH_TOKEN=sk-ant-oat01-…

# 4. Проверка вручную — должно написать «claude-tg запущен»
./.venv/bin/python -m claude_tg

# 5. Автозапуск
sudo cp deploy/claude-tg.service /etc/systemd/system/claude-tg.service
sudo $EDITOR /etc/systemd/system/claude-tg.service   # User= и пути
sudo systemctl daemon-reload
sudo systemctl enable --now claude-tg
```

Дальше:

```bash
sudo systemctl status claude-tg      # живой ли
sudo journalctl -u claude-tg -f      # логи в реальном времени
sudo systemctl restart claude-tg     # перезапуск
```

`Restart=always` в юните значит, что после ночного автообновления Claude Code
бот поднимется сам.

## Пошагово: Docker

Если на сервере уже есть Docker — короче:

```bash
git clone https://github.com/smmsemmers/claude_tg.git && cd claude_tg
cp .env.example .env && $EDITOR .env      # включая CLAUDE_CODE_OAUTH_TOKEN
docker compose up -d --build
docker compose logs -f
```

Данные (SQLite и рабочие папки) лежат в томе `claude-tg-data` и переживают
пересборку образа. Обновление Claude Code внутри контейнера делается
пересборкой: `docker compose build --pull && docker compose up -d`.

## Если что-то не работает

| Симптом | Причина и что делать |
|---|---|
| В логах `CLI \`claude\` не найден` | Не установлен Claude Code либо он не в `PATH` у пользователя сервиса. Поставь `npm i -g @anthropic-ai/claude-code` или пропиши `CLAUDE_CLI_PATH` в `.env` |
| Бот отвечает «Не смог запустить Claude» | Скорее всего авторизация. Проверь `CLAUDE_CODE_OAUTH_TOKEN` и что токен не отозван: на сервере `claude --version`, затем `echo привет \| claude -p` |
| Ошибки про регион / отказ в доступе | Сервер внутри РФ или IP из неподдерживаемого региона. Нужна машина в Европе |
| Бот молчит на сообщения в группе | Так и задумано: в группах он отвечает только на упоминание `@бот` или реплай |
| Процесс убивает OOM | Мало памяти. Возьми тариф с 1 ГБ или добавь swap: `fallocate -l 2G /swapfile && mkswap /swapfile && swapon /swapfile` |

## Безопасность

* `.env` содержит токен бота и ключ доступа к твоей подписке Claude — файл в
  `.gitignore`, не коммить его и не пересылай в чат.
* Держи режим доступа `default` (кнопки подтверждения) — на сервере Claude может
  выполнять команды.
* `bypassPermissions` на публичном сервере включать не стоит.
* Доступ к боту открывай только тем, кому доверяешь: у них будет выполнение
  команд на этой машине.
